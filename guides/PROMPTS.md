2. 단계마다 만들 것, 확인 방법(실행 명령이나 입력 예시), 완료 기준을 적는다

4. 서버는 0.0.0.0, 포트 8000. 입력 오류나 자료 파일 문제가 생기면 서버가 죽지 않고 화면에 안내 문구를 보여 준다
5. AGREEMENT에 없는 기능이나 라이브러리는 넣지 않는다. 필요하면 이유를 따로 적는다
계획만 세우고 멈춰.
